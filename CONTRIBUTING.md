# Contributing

Read the setup and verification steps in [README.md](README.md). Run the scene
tests and the browser check before submitting changes. Add a source and
attribution record to [PROVENANCE.md](PROVENANCE.md) for any new media or
dependency. Keep screenshots and sample projects free of private material.

Discuss bugs with reproducible steps, and review contributions based on the
work. Harassment, discrimination, threats, and sharing private information
without consent are unacceptable. Contact a maintainer privately about
conduct concerns.
